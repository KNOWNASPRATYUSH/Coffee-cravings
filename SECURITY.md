## Reporting a Vulnerability

We take the security of Coffee & Cravings, customer data, and our payment & ordering infrastructure seriously. If you discover a vulnerability, please report it responsibly so we can resolve it before public disclosure.

### How to Report

- **Email:** Send your report directly to **[cartnova.co@gmail.com](mailto:cartnova.co@gmail.com)** with the subject line `[SECURITY VULNERABILITY] Coffee & Cravings`.
- **GitHub Private Advisory:** Alternatively, navigate to the [Security Advisories](https://github.com/KNOWNASPRATYUSH/Coffee-cravings/security/advisories) tab of this repository and click **"Report a vulnerability"** to open a private advisory.

> [!IMPORTANT]
> **Please DO NOT file public GitHub Issues or PRs for security vulnerabilities.**

### What to Include in Your Report

To help us triage and patch the issue swiftly, please include:
1. **Description:** A concise explanation of the vulnerability and its potential impact (e.g., authentication bypass, data disclosure, SSRF, injection).
2. **Steps to Reproduce:** Clear, step-by-step instructions or Proof of Concept (PoC) code/HTTP requests.
3. **Environment:** Browser version, OS, or specific API endpoint tested (`/api/...`).
4. **Proposed Fix (Optional):** Any recommendations on how to patch the issue.

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your report within **24 to 48 hours**.
- **Assessment:** We will confirm the issue, rate its severity, and provide regular progress updates as we work on a fix.
- **Resolution:** Critical security patches will typically be released within **72 hours** of confirmation.
- **Credit:** If you wish to be credited for your discovery, we will acknowledge you in the patch notes upon public release.
